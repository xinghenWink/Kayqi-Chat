## 隔离环境与浏览器回归

本机 Go 服务监听 `127.0.0.1:18080`，模拟上游监听 `127.0.0.1:18081`。使用独立 SQLite、文件目录、测试管理员和普通用户；未读取生产密钥。浏览器验收使用默认并发 1，模拟接口分别延迟 1、5、20 秒以覆盖恢复过程。

已通过以下实际操作及接口核对：

1. 同一会话免费聊天 → 生图 → 生成图加入编辑 → 编辑 → 切回聊天理解图片；聊天与生图模型分别记忆。
2. 历史上传图/生成图加入参考，重复操作去重、移除；复用配置恢复父消息提示词、参考图及有效参数。
3. 低/中/高质量与已验证尺寸/数量控件；改价后重生成弹窗显示最新报价，确认后才提交。
4. 新会话第一次生图取得正式 URL 后保持生图模式；未发送的新草稿刷新后保持模式。
5. 生图运行中刷新，恢复同一个任务；完成后显示交付和消费，冻结积分自动归零，不重复结算。
6. 后台规则、模型能力保存、六项默认图片价格、用户永久积分增加与原因、流水和预留查询。
7. 普通用户零积分聊天成功、生图返回 402；其他用户不能读取测试管理员图片；管理员创建账号即使注册奖励临时设为 20 仍为零积分。

最后一次数据库核对：6 次浏览器图片任务共消费 32 积分；测试管理员先发放 50、后台追加 2，余额 20，日积分 0。没有重复流水引用、活动预留或活动暂存图片；原货币余额始终为 1,000,000,000 纳美元，没有重复扣除。
